## 绘图与切片的方位坐标复核（2026-11-25）

- 复核发现：地层切片原来使用 `cos(φ−90°)`，而井壁图使用 `cos(φ)`，倾斜地层产生了 90° 的方位错位。现统一到图像坐标：`z = z0 + R·cot(dip)·cos(φ)`。
- 裂缝切片原先的起伏符号也与绘图法向平面相反，现统一为 `z = z0 − R·tan(β)·cos(φ−α)`，同时修正弧长方向导数的符号。修复不改变第二页求解器或输入格式。
- 新增 `SliceCoordinateConsistencyTest`，覆盖两个实际地层和无界面背景中的裂缝，逐一比较全部 192 个方位的绘图几何、切片界面深度及裂缝局部斜率。修复前两项测试均失败，分别复现 0° 地层边界 0.1 m / 图像 0.042265 m、裂缝深度 0.8 m / 图像 0.7 m 的差异。
- 旧切片不会自动被改写；应用修复后应依次重新生成第一页图片/切片、第二页获得输入数据、正演计算、井壁成像，旧历史批次仍对应其原始输入。

- 验证结果：坐标修复后执行 `mvn -o -Dsimulation.materialTrial=true -Dsimulation.cubeTrial=true test`，共 145 项，141 项通过、4 项可选测试跳过，零失败、零错误；包含三种异常体及介电常数单独变化的真实求解器试算，均引起模值与相位变化。完整日志：`target/calculation-final-recheck-20261125.log`。
- 用户随后修改的第一份桌面文件为 `n=2`、倾角 30°、界面深度 0.1/0.2 m、电阻率 20/15/20 Ω·m；这表示三个实际地层，未覆盖用户修改。额外新增该参数组的全 192 方位材料归属与区间裁剪测试，单独补跑坐标测试共 3 项全部通过。日志：`target/coordinate-current-input-verification.log`。测试使用临时目录，不重写正式 C 盘切片或结果。

## 零界面、零异常体的输入规则（2026-11-25）

- `n` 是分层界面个数，不是实际材料层数。实际层数为 `n + 1`：两个实际地层使用 `n = 1` 和两个电阻率；无分层界面使用 `n = 0` 和一个背景电阻率。背景材料仍参与绘图与正演，不能把背景电阻率省略或设为 0。
- 裂缝、球体、正方体、楔形体、曲面文字的个数为 0 时，不填写该项的数据行。不能只把原来的数量改成 0 而保留旧参数，否则数量与数据不一致。地层界面为 0 时也不填写界面深度，只保留一条背景电阻率记录。
- 读取器允许空深度段、空裂缝段在分隔线或下一节标题处结束，不再跨段读取下一节的数字；数量与数据条数仍严格校验。界面数量输入及删除操作支持减到 0，保留一个电阻率和介电常数输入行。
- 无界面时，根据球体、正方体、楔形体、裂缝与文字的深度范围确定绘图范围；默认展开范围至少覆盖 0～1.5 m，并扩展以覆盖范围外的对象，避免没有地层界面时异常体被默认窗口裁掉。已有分层模型的默认深度范围不变。
- 正确格式示例及回归输入：`src/test/resources/formation-layers-only.txt`（两个实际地层、无异常体）、`src/test/resources/formation-anomalies-only.txt`（无分层界面、一个背景电阻率、三种异常体各一个）。
- 回归覆盖文件读取、零界面编辑和三种异常体的实际图形取样，以及全部 192 个方位的切片、材料转换和 2.54 mm 采样校验。生成和测试使用临时目录，不覆盖正式数据。

- 验证：首次零数量修正时，`mvn -o test` 共 143 项，137 项通过、6 项可选测试跳过，失败与错误均为 0。当时桌面两份修改后的输入文件与上述回归输入一致；后续手动编辑以当前文件为准。

## 使用

仍从 `Launcher` 启动，在原窗口切换到「电成像响应模拟」。

1. **获得输入数据**：默认按 `C:\Stratigraphic information\call.m` 的参数，从 `192_Slices_Output` 转换生成 `192_NGI_Input`，完成全部 192 个电极的格式、物性及重建剖面一致性校验后，备份并替换旧输入。输入快照保存原始切片、参考脚本及哈希记录。按钮右键菜单仍允许选择已转换目录，读取时不改写该目录；CSV、PNG 和 logs 子目录不作为电极输入。左侧不展示输入模型信息。
2. **正演计算**：开始前可设置「同时计算通道数」，默认值为本机可用逻辑处理器数（最多 192），可选范围为 1～192；选择 1 可串行。各电极使用独立工作目录，空闲位置自动分配下一个待计算电极。并行数量设置始终显示，任务运行期间禁止修改；计算进度显示当前电极及其实际深度点，优先显示编号最小的未完成电极。运行期间提供「暂停计算」「停止计算」；暂停后可在同一位置点击「继续计算」。停止和退出也保留完整电极，重启后可恢复未完成批次。
3. **生成图片**：每次点击均打开 TXT 选择窗口，可直接选择以前保存的完整结果，无需加载输入或执行计算；即使刚计算完，也由用户选择想绘制的文件。每次绘制一个文件中全部 192 个电极。取消选择或文件不合法时保留原图；成功选择后记住其目录。页面不展示历史文件提示。历史批次仍独立保存。模值对数色标、相位线性色标分别可调；滚轮对光标所在图的电极与深度方向同时等比例缩放，两张结果图分别保存缩放和平移状态。点击有效像素显示原始记录，分组间隙不返回数据。

左侧「有关计算结果信息」只显示当前结果 TXT 的统计及色标设置，不显示输入模型参数。首次进入时前两张图区为空；第三张同步第一页面已生成的彩色井壁图，尚未生成时显示操作提示。

## 暂停与恢复（2026-11-16 新增）

- 「暂停计算」先归档本轮已正常结束并通过校验的电极，然后结束本批其余求解进程，保存 `PAUSED_INCOMPLETE`，暂停期间不继续占用求解资源。「继续计算」沿用同一批次，只计算尚未完成的电极。
- 暂停、停止、退出均以**完整电极**为恢复单位。EXE 没有提供电极内部深度点的保存/恢复接口，正在计算但尚未完成的电极需要从头计算；已经完整归档的电极不会重算。暂停不是冻结 EXE 的内存状态。
- 再次打开第二页时，左侧「历史记录」按时间倒序列出全部可读取批次，显示完成状态、时间和已归档电极数量，不再限制最近三次。选中未完成批次后点击「继续所选计算」，无需重新获得输入数据。已完成批次仍显示，但禁用继续计算；其 TXT 可通过「生成图片」选择。正在其他任务中运行或已锁定的批次不提供恢复。没有记录时保留历史区域并显示空状态。
