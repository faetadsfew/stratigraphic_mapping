# 运行与演示环境说明

本文说明把本项目交给其他人演示时，需要准备的环境、数据和启动方式。

## 1. 最快方案：直接使用便携演示包

如果对方只需要**展示现有功能**，不需要改代码，推荐直接发送便携包：

```text
target\StratigraphicMapping-Windows-x64.zip
```

对方只需要：

1. Windows 10 / Windows 11，64 位。
2. 解压整个 zip 到任意可写目录。
3. 双击 `启动程序.bat`。

便携包内已经包含精简 Java 运行环境和全部依赖，**不需要安装 JDK、Maven、JavaFX，也不需要联网**。

内置示例数据在 `samples\formation_G.txt`。启动后点击「打开文件」选择它，再点击「生成图表」即可演示三维图、岩性剖面和井壁展开图。

全屏演示按 `F11`，退出全屏按 `Esc`。

如果双击没有窗口，运行 `启动程序-调试.bat`，把控制台报错发给开发者。

## 2. 源码运行方案

需要修改代码或重新构建时，按下面配置。

### 2.1 必需环境

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 操作系统 | Windows 10 / 11，64 位 | 第二页数值求解器仅支持 Windows |
| JDK | **JDK 17**（推荐 Microsoft OpenJDK 17） | 项目 `pom.xml` 编译目标为 Java 17；JavaFX 21 最低要求 JDK 17 |
| Maven | 不需要单独安装 | 项目自带 `mvnw.cmd` / `mvnw`，首次运行会自动下载 Maven 3.8.5 |
| JavaFX | 不需要单独安装 | 由 Maven 自动下载 JavaFX 21.0.6 |
| 磁盘 | 建议预留 1 GB | Maven 依赖、构建输出和演示包 |
| 内存 | 建议 4 GB 以上 | 求解器并行计算时按 CPU 核数占用内存 |
| 网络 | 首次构建需要 | 下载 Maven、JavaFX、POI、Log4j 等依赖；构建完成后可离线运行 |

安装 JDK 17 后确认：

```powershell
java -version
# 应显示 17.x

echo $env:JAVA_HOME
# 应指向 JDK 17 根目录
```

如果机器上同时装有多个 JDK，请让 `JAVA_HOME` 指向 JDK 17，而不是 21/26。

### 2.2 启动

在项目根目录执行：

```powershell
.\mvnw.cmd clean javafx:run
```

首次执行需要联网，之后依赖会缓存在本机 `%USERPROFILE%\.m2`。

### 2.3 在 IntelliJ IDEA 中运行

1. 用 IntelliJ IDEA 打开项目根目录。
2. `File > Project Structure > Project SDK` 选择 JDK 17。
3. 运行配置选择项目自带的 `Launcher`。
4. 主类为 `com.stratigraphic.mapping.Launcher`。
5. 建议 VM 参数：`--enable-native-access=javafx.graphics`。

也可以直接运行 `src/main/java/com/stratigraphic/mapping/Launcher.java`。

### 2.4 运行测试

```powershell
.\mvnw.cmd test
```

已验证结果：109 项测试，105 项通过、4 项跳过、0 失败、0 错误。

依赖已经下载完成后，可以离线执行：

```powershell
.\mvnw.cmd -o test
```

## 4. 数据与求解器依赖

### 4.1 第一页：地层剖面展示

不需要外部求解器。只需要一个 `formation_G` 格式的 TXT 参数文件。

项目自带示例：

```text
src\main\resources\com\stratigraphic\mapping\formation_G.txt
src\main\resources\com\stratigraphic\mapping\stratum-input.txt
```

参数文件支持 UTF-8、带 BOM 的 UTF-8、UTF-16 和 GBK 编码，程序会自动识别。

### 4.2 第二页：电成像响应模拟

真实计算需要外部求解器目录，默认路径为：

```text
C:\Stratigraphic information\
├─ NGI_2D_MFS_V2.exe        求解器主程序
├─ SOLVER_MUMPS_DLL.dll     求解器依赖库
├─ call.m                   输入转换参数脚本
├─ transf.m                 输入检查脚本
├─ 192_Slices_Output\       192 个电极的原始切片
├─ 192_NGI_Input\           转换后的求解器输入
└─ output\                  计算结果输出目录（必须可写）
```

注意事项：

- `NGI_2D_MFS_V2.exe` 同目录下的其它 DLL 也要一起提供。程序会把求解器同目录的依赖复制到每个电极工作目录。
- `call.m` 中的 `n_card` 必须为 192，输入/输出目录必须是工作根目录内的相对路径。
- `C:\Stratigraphic information` 需要写权限；计算会在其下创建 `output`、批次目录和日志。
- 不要求安装 MATLAB。`call.m` 只作为参数和转换规则参考，由 Java 代码解析，不执行 MATLAB。
- 仅展示已有计算结果时，可以不配置求解器，直接在第二页选择已有的结果 TXT 文件。

## 5. 显示与系统设置

- 推荐分辨率 1440×900 或更高；程序最小窗口为 1000×620。
- 程序启动时默认最大化，`F11` 切换全屏，`Esc` 退出全屏。
- 三维图使用 JavaFX 3D。远程桌面、虚拟机或显卡驱动异常时，3D 效果可能下降；正式演示建议本机运行并安装正常显卡驱动。
- Windows 默认自带中文字体（微软雅黑等），一般不需要额外安装字体。
- 如果启动时报 `VCRUNTIME140.dll` 或 `MSVCP140.dll` 缺失，安装 Microsoft Visual C++ 2015-2022 Redistributable (x64)。
- 程序运行时不监听端口，也不需要网络。

## 7. 为什么不用 `mvn javafx:jlink`

本项目依赖 Apache POI，其传递依赖包含 `commons-math3`、`SparseBitSet` 等自动模块。`jlink` 不能链接自动模块，直接执行：

```powershell
.\mvnw.cmd javafx:jlink
```

会报类似错误：

```text
自动模块不能用于 jlink: com.zaxxer.sparsebitset
```

因此便携包采用「精简 JRE + 应用 jar + 依赖目录 + 启动脚本」的方式，不依赖 `javafx:jlink`。
